## Abstract

How to take an idea, put it in progress and then complete it

## Steps

1. Start with a doc that describes the idea and outlines steps to make it reality
1. We have different types of docs:
    1. Overall docs that describe a high level concept
    1. Specific docs that build a feature in that concept
    1. General thoughts in the form of a doc
1. Write in markdown with a specific tag for tracking
1. Creating a doc initiates a tracking bug for the doc, labelled with doc
1. Deleting the doc, closes the bug
1. Marking the doc as Published closes the bug
1. If the doc has a section marked Tasks, once we publish the doc it creates a tasklist for managing said tasks
1. Docs are added / updated with an appropriate markdown linter
1. Once published docs are added to a website and published there under the appropriate project
